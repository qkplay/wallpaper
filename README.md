# HTML Live Wallpapers

مستودع بسيط لتشغيل صفحات HTML متحركة كخلفيات سطح مكتب، مناسب للتجربة مع:
- Lively Wallpaper
- Wallpaper Engine
- أي متصفح عادي

## التشغيل على GitHub Pages

1. أنشئ Repository جديد باسم مثلًا:
   `html-live-wallpapers`

2. ارفع كل الملفات الموجودة هنا.

3. من إعدادات الريبو:
   Settings → Pages

4. اختر:
   Source: Deploy from a branch  
   Branch: main  
   Folder: /root

5. بعد التفعيل سيكون الرابط مثل:
   `https://USERNAME.github.io/html-live-wallpapers/`

## روابط الصفحات

- الرئيسية:
  `/index.html`

- راديو القرآن:
  `/wallpapers/quran-radio/`

- ساعة متحركة:
  `/wallpapers/clock/`

## ملاحظة مهمة عن الصوت

لو برنامج الخلفيات يوقف الصوت عند فتح البرامج، افتح صفحة الراديو في المتصفح أيضًا، واضغط:
`Open Audio Window`

فتبقى الخلفية شكل، والصوت يعمل من نافذة مستقلة.
